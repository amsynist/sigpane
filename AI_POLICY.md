# AI Usage Policy

AI tools are welcome in Sigpane. These rules keep contributions reviewable:

- **Say when you used AI, and how.** Name the tool (for example Claude Code, Codex or Cursor) and how much of the work it did.
- **Understand what you submit.** You must be able to explain what your change does and how it fits the rest of the app without the tool's help. Code you can't explain will not be merged.
- **Review and edit AI-written text.** Issues, pull request descriptions and comments may be drafted with AI, but a person must read, check and trim them before posting.
- **Test it yourself.** Build and run the change, and run the tests, before you open a pull request. Don't post output you haven't checked.
- **No AI-generated media** (images, video, audio) in contributions unless the pull request is about that media and says how it was made.

This policy is adapted from the [AI usage policy of the Ghostty project](https://github.com/ghostty-org/ghostty/blob/main/AI_POLICY.md), which Sigpane is based on. Its rules apply to contributions to Ghostty; this file applies to contributions to Sigpane.
